# מבנה הדוח — `research/YYYY-MM-DD-מחקר-מתחרים.md`

הדוח בעברית, לבעל העסק — לא לאנליסט. משפטים קצרים, מספרים עם הקשר.

## תבנית

```markdown
# מחקר מתחרים ברשתות — {תאריך} · {רשת}

## שורה תחתונה
3–5 משפטים: מה המצב מולך ומה ההזדמנות המרכזית. נכתב אחרון.

## טבלת ההשוואה
| | אתה | מתחרה א' | מתחרה ב' | מתחרה ג' |
|---|---|---|---|---|
| עוקבים | | | | |
| פוסטים/שבוע | | | | |
| תמהיל (רילז/קרוסלות/תמונות) | | | | |
| מעורבות מנורמלת (חציון) | | | | |
| הנושא החזק | | | | |

המשתמש — תמיד העמודה הראשונה. תא בלי נתון: "לא נמצא", לא ריק ולא ניחוש.

## {מתחרה א'} — @handle
- המספרים: עוקבים, תדירות, תמהיל, מעורבות (ממוצע + חציון).
- **3 הפוסטים החזקים:** [קישור] — סוג + נושא + מעורבות. לכל אחד שורה.
- פילוח נושאים: אילו קטגוריות תוכן ואיזו מעורבות לכל אחת.
- התרשמויות (אם יש): תמיד "נראה ש..." + על סמך מה.
- **מה לומדים מהם:** דבר אחד שעובד להם, במשפט.

## שלוש הזדמנויות תוכן
כל אחת = פעולה + נימוק מהדאטה:
1. **[פעולה]** — [המספרים שמאחוריה]
   (למשל: "תעבור לקרוסלות טיפים — אצל 3 מתחרים זו הקטגוריה עם מעורבות כפולה מהממוצע, ואצלך אין אף אחת")
2. ...
3. ...

## מה השתנה מאז {תאריך}   ← רק בריצה חוזרת
- שינויי תדירות · פורמט חדש שנכנס · קפיצת/צניחת מעורבות · קצב צמיחת עוקבים

## מה לא נבדק
רשתות שלא נסרקו · פרופילים שלא אותרו/פרטיים · משיכות חלקיות (כמה מתוך כמה).
```

## ריצה בלי הפרופיל של המשתמש

הטבלה בלי עמודת "אתה" (המתחרים בלבד), ההזדמנויות מנוסחות "מה עובד אצלם שכדאי
לאמץ" במקום השוואה ישירה, ובסוף הדוח: *"כשתרצה השוואה מולך — הוסף את הפרופיל
שלך ב-competitors.md והרץ שוב."* שאר הדוח זהה.

## ריצה עם מתחרה אחד

הכול נשאר, חוץ מ: אין סעיפי "חוזר אצל כמה מתחרים" (אין הכללה ממדגם של 1),
וההזדמנויות נשענות על הפער הישיר בין המשתמש למתחרה. חובה לסיים בשורה:
*"הדוח מבוסס על מתחרה אחד — להוסיף 2–4 מתחרים בריצה הבאה לזיהוי דפוסי שוק."*

## כללי ניסוח

- הזדמנות = פעולה שאפשר להתחיל השבוע, עם המספרים שמצדיקים אותה.
- מעורבות תמיד מנורמלת ועם ההקשר: "2.1% (חציון) מול 0.8% אצלך" — לא "יש להם יותר לייקים".
- לא לדרג "מי הכי חזק" — משווים ממדים.
- ויראלי בודד ≠ אסטרטגיה: אם פוסט אחד מעוות את התמונה, לומר זאת ולהשוות בחציון.
- בלי שיפוטיות על מתחרים ("תוכן חלש") — רק מה עובד, מה לא נוכח, ומה המספרים.
