# 🎯 מנוע מחקר ומיצוב מתחרים בלינקדאין (LinkedIn Competitor Research App)

אפליקציה חכמה למיפוי, ניתוח והשוואת נוכחות לינקדאין של העסק שלך מול מתחרים ידועים ומאותרים אוטומטית.

פותח על ידי **דנבר (DANBAR) — ייעוץ אסטרטגי, משאבי אנוש והטמעת בינה מלאכותית**.

---

## 🌟 יכולות מרכזיות

1. **הגדרת עסק היעד:** הזנת פרטי העסק/המנהל (שם, תיאור, אתר ופרופיל לינקדאין ראשי).
2. **מתחרים ידועים:** הוספת קישורים של מתחרים ספציפיים בלחיצת כפתור (`+ הוסף מתחרה ידוע`).
3. **איתור מתחרים אוטומטי (Auto-Discovery):** זיהוי והצעת מובילי שוק רלוונטיים באותה נישה (מלונאות, טרוול-טק, HR ועוד) לבחירה בתיבות סימון.
4. **סריקה ישירה מול Apify:** חיבור ישיר ל-REST API של Apify לשאיבת פרופילים ופוסטים ללא צורך ב-Cookies או בהתחברות לחשבון.
5. **ניתוח השוואתי מתקדם:** השוואת עוקבים, קשרים, סגנונות מיצוב (B2B, סמכותי, סיפורי) והפקת 3 הזדמנויות תוכן קונקרטיות.
6. **ייצוא כפול:** תצוגה מקדימה מלאה באפליקציה והורדה ישירה של קובץ Markdown וקובץ PDF מעוצב עם תמיכה מלאה בכיווניות עברית (RTL).
7. **ארכיון דוחות:** צפייה והורדה חוזרת של דוחות היסטוריים ישירות מהממשק.

---

## 🚀 התקנה והרצה מקומית

### דרישות קדם:
* Python 3.10 ומעלה
* מפתח Apify API (שמור בקובץ `.env` או מוזן בממשק)

### הפעלה מהירה (Windows):
פשוט לחץ פעמיים על:
```bat
run_app.bat
```

### הפעלה ידנית מטרמינל:
1. התקן את התלויות:
```bash
pip install -r requirements.txt
```
2. הגדר את מפתח ה-Apify שלך בקובץ `.env`:
```env
APIFY_TOKEN=your_apify_token_here
```
3. הפעל את האפליקציה:
```bash
streamlit run streamlit_app.py
```
הדפדפן ייפתח בכתובת: `http://localhost:8501`

---

## 🌐 פריסה בענן (Vercel & Streamlit Cloud)
* **Vercel:** האפליקציה כוללת מתאם Serverless FastAPI ודשבורד מובנה בנתיב `api/index.py` ומוכנה לפריסה בלחיצה אחת ב-Vercel.
* **Streamlit Cloud:** ניתן לחבר ישירות ל-GitHub ולהגדיר את `streamlit_app.py` כקובץ הראשי.
